# Data in `research/` — sources and licences

The research folders contain data derived from third-party open datasets. Shared together
with this repository, they remain under their original licences:

| Data | Source | Licence |
|---|---|---|
| Building footprints and the areas/centroids computed from them (`pilot-emek-hefer/data/`, `prospects-emek-hefer-park/` outputs) | Microsoft Global ML Building Footprints — https://github.com/microsoft/GlobalMLBuildingFootprints | Community Data License Agreement – Permissive 2.0. The full text is in [`LICENSE-CDLA-Permissive-2.0.txt`](LICENSE-CDLA-Permissive-2.0.txt) (§2.1: shared Data must be accompanied by this text). |
| Buildings, land use, addresses, streets, points of interest and mapped solar, and data derived from them (`pilot-emek-hefer/data/`, `pilot-emek-hefer/audit/`, `prospects-emek-hefer-park/` outputs) | © OpenStreetMap contributors — https://www.openstreetmap.org/copyright | Open Database License 1.0 (ODbL) — https://opendatacommons.org/licenses/odbl/1-0/. Derived databases that are shared publicly are offered under the ODbL. |
| Reverse-geocoding results | OpenStreetMap Nominatim | Same as OpenStreetMap (ODbL). |
| Company registry extracts | רשם החברות — data.gov.il, dataset `ica_companies` | data.gov.il terms of use: reuse permitted with attribution to the source. |
| Irradiation estimates | PVGIS, European Commission JRC | © European Union; reuse permitted with attribution. |

No aerial imagery or map tiles are stored here; imagery was used for display only.

The business contact data collected in the prospect pilot (`prospects-emek-hefer-park/data/`
and `discovery/`) is internal, admin-only material and is not part of this repository.
